# ♟️ Lichess Player Analyzer

Консольная утилита, которая по нику на [Lichess](https://lichess.org) **стримит последние партии игрока из облака** и выводит подробную статистику прямо в терминале. Ничего не скачивается на диск: партии обрабатываются на лету, в памяти хранятся только счётчики.

## Возможности

- 📊 Результаты по цвету фигур (победы / ничьи / поражения, винрейт)
- ⏱️ Статистика по контролю времени (bullet, blitz, rapid, classical)
- 📖 Топ дебютов отдельно за белых и за чёрных
- 💪 Сильные и слабые дебюты (от 5 партий)
- 🏁 Как заканчиваются партии: мат, время, сдача, пат
- 🌙 Винрейт по времени суток (ночь / утро / день / вечер)
- 📏 Средняя длина партий и доля быстрых партий
- 📈 График изменения рейтинга в терминале

## Установка

Нужен Python 3.9 или новее.

```bash
git clone https://github.com/konaaakonaaa/lichess-player-analyzer.git
cd lichess-player-analyzer
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Использование

```bash
# 500 последних партий (по умолчанию)
python analyzer.py DrNykterstein

# только блиц, 200 партий
python analyzer.py DrNykterstein -n 200 --perf blitz

# интерактивный ввод ника
python analyzer.py
```

| Параметр | Описание |
|---|---|
| `username` | Ник игрока на Lichess |
| `-n` | Сколько партий анализировать (по умолчанию 500) |
| `--perf` | Фильтр режима: `bullet`, `blitz`, `rapid`, `classical` |
| `--token` | Личный токен Lichess (необязательно, ускоряет загрузку) |

Выход в любой момент: **Ctrl+C**.

## Как это работает

1. Запрос к публичному эндпоинту `GET /api/games/user/{username}` в формате NDJSON.
2. Партии приходят потоком, каждая обрабатывается функцией `analyze()` и сразу забывается.
3. Из счётчиков функция `show()` строит таблицы через библиотеку [rich](https://github.com/Textualize/rich).
4. При ответе `429` программа ждёт 60 секунд и повторяет запрос, как просит документация Lichess.

## Ограничения

- Без токена API отдаёт примерно 20 партий в секунду, 500 партий занимают порядка 30 секунд.
- Анонимные соперники и игроки, закрывшие аккаунт, не учитываются.
- Анализ основан на результатах и дебютах, движок Stockfish пока не используется.

## Fair play

Проект только читает **публичные данные** через официальное API и ничего не делает в самих партиях. Не используйте подобные инструменты для подсказок во время игры с живыми людьми: это нарушает [правила Lichess](https://lichess.org/terms-of-service).
